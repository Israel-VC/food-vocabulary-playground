# Food Lab — GitHub Pages

A visual English vocabulary page about **Countable & Non-Countable Nouns and Quantifiers**. The introduction and activity structure are inspired by the [Adjectives page from Learning & Development Studio](https://learning-development-studio.github.io/english-hub/A1.1/adjectives/). It includes 24 words with audio, a flashcard deck, picture phrases, three games, and a pair activity.

## Publish on GitHub Pages

1. Create a GitHub repository and upload `index.html`, `styles.css`, `reference-style.css`, and `script.js` to its root.
2. Open **Settings → Pages** in that repository.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, and choose `/ (root)`.
4. Save. GitHub will show the page URL after deployment finishes.

To preview locally, open `index.html` in a browser. Pronunciation uses the browser's available speech voice. The activities work offline; Google Fonts requires a connection and has local fallback fonts.
